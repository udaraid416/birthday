# Birthday Surprise
Static site, no build step.
- `index.html` page markup
- `css/style.css` styles
- `js/config.js` YOUR settings (date, unlock code, photos, song, video)
- `js/main.js` scenes, Three.js background, music player
- `assets/` your photos, song.mp3, moment.mp4

## Host on GitHub Pages
Repo -> Settings -> Pages -> Deploy from a branch -> `main` / `(root)` -> Save.
